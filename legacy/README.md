# Legado

Copiar para esta pasta, sem modificar, a última versão clínica validada:

`AGA-1.html`

Ela será usada como **golden master** para testes de equivalência durante a migração.

Não remover até que:
1. todas as escalas tenham testes;
2. todas as intervenções tenham testes;
3. SOAP, relatório e medicamentos tenham equivalência/revisão clínica;
4. a nova aplicação tenha passado pelo QA longitudinal.
